Hello! Here is a full readme for superscript.
 
 1. Node

You need to have Node.js, which you probably have.

 2. Multiple-line code

You can use the commands and syntax to write it in multi_line_code.ss

 3. Commands

You can type ‘help’ in the command line, (when you type ‘node superscript.js’) which shows a list of commands.

 Quick note: In the command line, it can only run a single line of code when you type. And use VS Code terminal too. 

(PS, Terminal and CMD are spooky)
